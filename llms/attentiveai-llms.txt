# Attentive.ai

> Attentive.ai builds AI-powered software for the construction and outdoor services industries, automating property measurements, takeoffs, and estimating from aerial imagery and blueprints. Backed by Insight Partners. No public developer API or OpenAPI is currently published; this profile captures identity, security posture, and site link properties.

## Products
- [Automeasure](https://attentive.ai/): AI property measurement from aerial imagery for landscaping, paving, and snow-removal contractors
- [Beam AI](https://www.ibeam.ai/): Automated construction takeoffs and estimates
- [BIM CoPilot](https://attentive.ai/bim): BIM modeling, clash detection, BOQ generation, and as-built documentation
